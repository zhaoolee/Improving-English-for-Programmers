程序员工作英语 底图风格模板：极简黑白火柴人（当前：黑底白线）
============================================================

当前默认 / 未来批次方向
----------------------
- 黑底白线：纯黑背景 + 白色线条火柴人，底图内无任何文字或对话气泡。
- **新卡直接生成黑底白线**（每卡新 photoID），无需先生成白底再反色。
- **旧批（V1–V5 那 32 张）**：已审核的「白底黑线」原图通过**精确 RGB 反色**得到黑底白线，
  再经官方换图接口在**原 V5 photoID** 上替换（V7，保留原 ID/顺序）；白底原图永久保留。
- 反色：ImageMagick `-channel RGB -negate +channel`（不反色 alpha），尺寸不变；
  批量脚本 `scripts/invert-images.sh`；校验反色再反色回原图 AE=0。

核心视觉
--------
- 纯黑背景，干净、统一的白色线稿。
- 成年火柴人：圆形头部、简单表情、细线条四肢，呈现程序员工作与沟通场景。
- 单幅完整场景，无分镜；无渐变、无阴影、无写实照片质感。
- 克制、精致的程序员职场漫画审美。

构图
----
- 方形 1024x1024（本专题成品 1254x1254）。
- 人物与关键道具集中在 x≈180..820、y≈220..790（0..1000 画布）。
- 四周保留空白，便于之后添加学习标签。
- 命名的学习道具清晰可辨、完整可见、互不遮挡。
- 用姿势与手势体现对话；不画对话气泡。

禁止
----
- 不出现任何文字、字母、数字、可读代码、字幕、标签、品牌、水印或二维码。
- 不使用颜色、渐变或写实渲染。
- 不画多格漫画、装饰性数学符号或无关道具。
- 允许简单抽象 UI 标记（无文字）。

标签关系
--------
- 黑底白线底图；学习标签使用 workflow/label-palette.json 的协调配色与白色文字。
- 可定位对象在最终底图上人工框选（cards 0–1、PicLex 0–1000）。
- 抽象词、功能词使用对白语境，不编造框。

历史与来源
----------
- 原「白底黑线」模板保存在 `workflow/styles/stick-figure-white-background.txt`（provenance）。
- 已发布 V1–V5 为白底黑线；V6 为黑底白线新 photoID 版本；V7 在**原 V5 photoID** 上换为黑底白线并公开发布；此后各批均为**直接生成黑底白线**（非反色）的新 photoID。
- 当前公开 V10：本地/已公开 **80 图 / 320 词条 / 224 唯一词 / 85 局部框 / 235 语境词**（每类 10 张）。V6 曾因新 photoID 导致手机更新后练习为空（历史问题），由 V7 保留原 V5 ID 换图修复；新增批次正常使用新 ID。
- 80 张计划卡已全部完成，无下批。
