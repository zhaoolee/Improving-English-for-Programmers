# 程序员面试

本专题沿用本仓库的英语场景卡方向，面向程序员在英语面试中的真实沟通：介绍经历、解释技术、回应追问和沟通求职事项。首版是跨岗位通用的八类规划，兼顾初级与有工作经验的开发者；系统设计类可按岗位级别选择学习深度。

首版分为 **8 个子专题，每类 5 期，共 40 张场景卡（I001–I040）**。目录及图片 prompt 已准备（48 条），其中 I001–I040 共四十张场景底图已生成并完成 Codex 底图视觉审查（其中 I003/I005/I007/I013/I017/I028/I038 七张按词条需求做过定向换图，被替换前的旧图备份见下文），剩余 0 张；已创建独立一次买断付费工作台草稿，40 张底图已上传为照片（封面为 I001），**40 张卡已全部制作并导入工作台（`status=approved`，共 160 个词条、128 个不同词）**。App Store Connect 已创建对应非消耗型商品，中国大陆基准价 ¥18；卡组与商品均未提交发布或开售。（历史：内容导入前本专题为 0 学习词条、词条与对白待定稿。）

## 推荐规模

- 8 类，每类 5 期，共 **40 张场景卡**（I001–I040）。
- 每卡包含一句双语场景描述、4 话轮 A,B,A,B 原创对白、4 个目标词（1 关键词 + 3 配套词）；本批 40 卡共 **160 个词条、128 个不同词**（部分词跨卡复用）。
- A 是候选人/学习者，B 是面试官或招聘方；角色说明独立保留。

这八类按学习目标组织，各公司与岗位的面试流程可能不同。

## 分类边界

- 项目类以已做项目的事实、个人贡献和结果为主；行为类以经历中的人际协作、决策与成长为主。
- 技术基础类解释概念；系统设计类在约束下组织完整方案；工程实践类解决给定代码、测试或故障场景。
- 与程序员工作英语保持独立：相似词可复用，具体情境转为候选人回应面试追问，不复制旧对白。

## 通用英语沟通与后续扩展

全专题贯穿澄清问题、说出思路、请求重复、坦诚表达不确定与接受提示；这些表达放入相应场景，不单独设类。

岗位扩展（前端、后端、移动端、数据与 AI、测试与运维、技术管理）在首版 40 张之后独立追加，不计入本次规划。
