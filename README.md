# Basic English 850 Words / 基础英语850单词

Basic English 850 words 是一种基础英语词汇表，包含了850个常用的英语单词。这个词汇表旨在帮助非英语为母语的人学习英语，以便能够进行基本的日常交流。这些单词被认为是最常见和最基础的英语词汇，涵盖了各种常见的主题和概念。通过掌握这些基础词汇，学习者可以构建起初步的英语语言能力，并逐渐扩展词汇量和语言技能。

### C001 · 清晨醒来

<img src="scene-cards-850/workflow/references/instagram-warm.png" width="480" alt="C001 清晨醒来">

| 单词 | 中文 | 例句 |
| --- | --- | --- |
| bed | 床；用来睡觉的家具 | I am still in **bed**.<br>我还在床上。 |
| sleep | 睡觉；处于睡眠状态（本例回顾昨夜） | I **slept** well last night.<br>我昨晚睡得很好。 |
| awake | 醒着的；没有在睡觉 | I am **awake** now.<br>我现在醒着。 |
| morning | 早晨；一天中醒来后至中午前的一段时间 | The room is bright this **morning**.<br>今天早晨房间很明亮。 |
| clock | 钟；摆放或悬挂的计时器 | The **clock** is beside my bed.<br>钟在我的床边。 |
| curtain | 窗帘；挂在窗前遮挡光线的布 | Light comes past the **curtain**.<br>光从窗帘旁边透进来。 |
| light | 光；本卡指从窗外照入的自然光 | **Light** falls on the bed.<br>光照在床上。 |
| early | 早的；本卡指一天刚开始、时间还早 | It is still **early**.<br>时间还早。 |
| be | 系动词，用来说明状态；本卡以 am/is 连接主语与状态或位置 | I **am** awake now.<br>我现在醒着。 |
